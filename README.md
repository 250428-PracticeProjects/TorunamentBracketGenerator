# Simple Tournament Bracket Generator 🎾

A web application to create and manage single-elimination tennis tournaments.

## Features
- Add players to a tournament.
- Automatically generate a single-elimination bracket.
- View and update match results.
- Players automatically advance through the rounds.

## Tech Stack
- **Backend:** Spring Boot
- **Frontend:** React
- **Database:** PostgreSQL

## How It Works
1. Add players through the player entry form.
2. Generate the tournament bracket based on the list of players.
3. View the bracket and update winners after each match.
4. Track tournament progress until a final champion is crowned!

## Project Structure
- **Spring Boot Backend:** Handles player management, match generation, and result updates.
- **React Frontend:** Provides user interfaces for adding players, viewing the bracket, and setting winners.
- **PostgreSQL Database:** Stores players and match data.

## Future Improvements
- Support for tournaments with byes (non-power-of-2 player numbers).
- Add match history and statistics.
- Enhance bracket visualization with animations.
